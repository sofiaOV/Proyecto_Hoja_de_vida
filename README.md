# [Nombre de tu proyecto] Sistema de Vacantes Laborales
## Descripción	 [Aplicación web desarrollada en HTML, JavaScript y Bootstrap que permite registrar candidatos para vacantes laborales, guardar su información en el navegador y visualizar o eliminar documentos adjuntos.]
## Lenguaje	 [HTML5, JavaScript, Bootstrap]
## Funciones	 - formulario.onsubmit: Captura los datos del candidato y guarda la información en localStorage.
- verArchivo(): Permite visualizar imágenes o abrir archivos PDF adjuntos.
- render(): Muestra en pantalla la lista de candidatos guardados.
- localStorage.setItem(): Guarda la información de los candidatos en el navegador.
- localStorage.getItem(): Recupera los candidatos almacenados.
## Como ejecutar	Abre el archivo Hoja de vida.html en cualquier navegador
